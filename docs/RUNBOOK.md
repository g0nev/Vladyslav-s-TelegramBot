# Runbook: права бота в группе

Это инструкция для человека, который администрирует бота в Telegram-группе — не часть кода, бот её не читает.

## Как выдать боту права

1. Откройте группу → «Управление группой» (или иконка карандаша) → **Администраторы**.
2. Найдите бота в списке (или добавьте через «Добавить администратора», если ещё не добавлен).
3. Включите тумблеры из таблицы ниже — под соответствующие функции бота.
4. Сохраните.

## Какое право за что отвечает

| Право в Telegram | Что даёт боту | Какие команды/функции без него не работают |
|---|---|---|
| **Блокировка участников** (`can_restrict_members`) | Мьютить и кикать нарушителей | Автомодерация по триггер-словам, `mute_user`/`kick_user` через `/ask` |
| **Закрепление сообщений** (`can_pin_messages`) | Закреплять/открепять сообщения | `/pin`, `/unpin` |
| **Изменение профиля группы** (`can_change_info`) | Менять название/фото/описание, менять права участников чата | `/lock`, `/unlock`, `/settitle`, `/setdescription`, `/setphoto` |
| **Приглашение пользователей по ссылке** (`can_invite_users`) | Создавать/отзывать инвайт-ссылки, одобрять заявки на вступление | `/newlink`, `/revokelink`, кнопки «Одобрить/Отклонить» на заявках |

Первое право («Блокировка участников») нужно было и раньше, для модерации. Остальные три — новые, добавлены вместе с командами управления группой.

## Что будет, если забыть выдать право

Ничего не сломается и не упадёт с ошибкой. Бот в ответ на команду напишет что-то вроде «Боту не хватает прав на …» — и всё. Просто соответствующая команда не будет работать, пока право не выдадут.

## Заявки на вступление

Чтобы кнопки «✅ Одобрить» / «❌ Отклонить» вообще появлялись, в группе должна быть включена опция **«Заявки на вступление»** (Настройки группы → Разрешения → «Одобрять новых участников»). Если она выключена, люди вступают сразу, и событие заявки боту не приходит — это ожидаемо, не баг.
