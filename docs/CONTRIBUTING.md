# Contributing

Thanks for taking the time to improve the bot.

## Before opening a pull request

- Keep changes focused on one problem.
- Add or update tests for changed behavior.
- Run `pytest` locally.
- Do not include `.env`, bot tokens, Telegram sessions or local database files.
- Update the relevant documentation when setup or behavior changes.

## Pull request checklist

- The test suite passes locally.
- The change has a clear description.
- Configuration changes are reflected in `.env.example`.
- No secrets or generated local files are included.
